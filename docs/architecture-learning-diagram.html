📩 Path A - Normal Save (REST) Example: Create Task

1. You drag Kanban card → React calls fetch('/api/tasks', {Bearer JWT})
2. Vite proxy :8081 → :5000
3. Middleware checks JWT → OK
4. taskRoutes.js → ProjectTask.create() → MongoDB saves
5. Redis clears project cache + Socket /tasks emits to teammates
6. 200 OK goes back up → TanStack Query updates UI, no reload

⚡ Path B - Live Typing (Socket) Example: Notes

1. You type → Yjs updates local screen in 0ms + saves to IndexedDB
2. SocketIOProvider emits note-update [12,45,200...] to /notes room
3. Server does NOT open it, just forwards socket.to(noteId).emit() to friend
4. Friend Yjs merges bytes → text appears live
5. Later background worker saves full blob to MongoDB (debounced)

🐙 Path C - Reverse (GitHub → You) Example: git push

1. You push code → GitHub POSTs to /api/github-app with signature
2. verifyGithub HMAC checks rawBody → queue (202 Accepted) → worker finds linked Project
3. Groq analyzes commits OR regex finds TASK-102 → Mongo updates lastWebhookAiSummary
4. /tasks socket pushes projectUpdate → your Kanban auto-refreshes

1. Login flow: Login.tsx → firebase.ts → auth-headers.ts → authMiddleware.js → userRoutes sync → Mongo User
2. One REST: useProjects.ts → projectRoutes.js → Project.js → Mongo → Redis
3. One Socket: ChatView.tsx → chatSocketService → chatSocketHandler.js → Message.js
4. One AI: generateProjectRoutes.js → taskGenerator.js (Groq) → bulk insert
5. One webhook: githubAppWebhook.js → webhookQueue → githubWebhookWorker.js
